# Migration Guide: `ios-v1.0.7` → `ios-v1.0.10`

---

## Breaking Changes (required)

### `AstroConfiguration` requires 2 new parameters

The initializer now requires `clientId` and `partnerUserId`. Without them it won't compile:

```swift
// BEFORE (v1.0.7)
AstroConfiguration(
    environment: .production,
    token: "...",
    theme: .light
)

// NOW
AstroConfiguration(
    environment: .production,
    token: "...",
    theme: .light,
    clientId: "your-client-id",       // REQUIRED
    partnerUserId: "user-123"          // REQUIRED
)
```

## Deprecations (non-breaking, but should be removed)

| Deprecated | Replace with |
|---|---|
| `showCloseButton` | `showHeader` |
| `autoSize` | `showHeader` |

Still functional but will produce compiler warnings.

## New Optional Parameters

### Phone data

```swift
phoneCode: "+54",        // optional
phoneNumber: "11..."     // optional
```

### Custom styling

```swift
style: AstroStyle(
    backgroundColor: "#F5F5F5",
    header: AstroHeaderStyle(
        backgroundColor: "#FFFFFF",
        borderColor: "#E0E0E0",
        borderWidth: 1,
        paddingHorizontal: 8,
        paddingVertical: 8
    )
)
```

> **Note:** When `style` is not provided, the SDK uses default colors based on the selected theme (light/dark/system).
>
> **Important:** When you override a color via `AstroStyle`, the SDK **stops using the theme-based default** for that property. This means you are responsible for providing the appropriate value for both light and dark modes. For example:
>
> ```swift
> let isDark = UITraitCollection.current.userInterfaceStyle == .dark
>
> let style = AstroStyle(
>     backgroundColor: isDark ? "#041311" : "#FFFFFF",
>     header: AstroHeaderStyle(
>         backgroundColor: isDark ? "#061E1D" : "#EFEFEF"
>     )
> )
> ```

### Issuer logo in header

```swift
showHeaderLogo: true   // displays issuer logo
```

### Biometric grace period *(only if using biometrics)*

```swift
biometricGracePeriod: 120   // seconds (0–600), default 120
```
